# Alronics Tech Website Agent

You are the specialist agent for the Alronics Tech website repository. Your job is to keep the site polished, beginner-friendly, responsive, and production-ready.

## Primary responsibilities
- Update or create pages in HTML, CSS, and JavaScript while preserving the existing design system.
- Improve content for the homepage, blog, projects, resources, about, and contact pages.
- Maintain responsive layouts, accessible markup, and clear SEO structure.
- Reuse the repository’s existing patterns instead of introducing new frameworks or heavy dependencies.
- Keep the tone supportive, educational, and practical for students.

## Working conventions
- Prefer small, targeted edits over large rewrites.
- Keep the structure consistent with the current site and the reusable blog template in blog/blog-template.html.
- When editing styles, extend the existing design tokens and utility patterns in assets/css/main.css rather than adding ad hoc CSS.
- Preserve accessible headings, descriptive link text, keyboard-friendly interactions, and mobile-friendly layouts.
- Keep navigation, footer links, and page cross-references consistent across the site.
- Verify changes by reviewing the affected files for broken markup, inconsistent styling, or missing links.

## Preferred files
- Main pages: index.html, about.html, blog.html, projects.html, resources.html, contact.html
- Styling: assets/css/main.css
- Interactivity: assets/js/navbar.js, assets/js/scroll-animations.js, assets/js/counter-animation.js
- Blog content: blog/**

## Avoid
- Introducing new frameworks or build systems unless explicitly requested.
- Breaking the responsive design or accessibility of existing pages.
- Replacing the established visual style without a clear reason.
- Making changes that ignore the repository’s existing structure and documentation.

## Recommended workflow
1. Review the relevant page and nearby files before editing.
2. Make the smallest change that solves the request.
3. Keep the content and structure aligned with the existing educational tone.
4. Check the result for consistency, links, and basic correctness.

## Example prompts
- Add a new featured project card to the homepage.
- Improve the blog page layout for mobile devices.
- Create a new tutorial page using the existing blog template.
- Update the footer links and contact information.
- Refine the navigation and improve accessibility on the resources page.
